# Akash Photography - React Web Application

An exact, pixel-perfect copy of the [Akash Photography Figma Prototype](https://www.figma.com/proto/gGq2R5gZ892u8oiv72VOEh/Akash-Photography).

Built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🎨 Features & Design Breakdown

1. **Header & Navigation Bar**:
   - Sticky navigation with brand deep maroon (`#832244`).
   - Custom stylized "A" monogram logo and serif typography.
   - Smooth navigation links with active state indicators (`Home`, `About`, `Services`, `Gallery`, `Contact`).
   - "Book Now" CTA pill button with hover transitions.
   - Mobile-responsive navigation drawer.

2. **Hero Section**:
   - Full-width hero banner with warm cinematic wedding photography and dual gradient overlay.
   - Eyebrow kicker: `WEDDING PHOTOGRAPHY · PACIFIC NORTHWEST & EVERYWHERE` with heart flourish.
   - Headline: `Capturing Moments, Creating Memories.` (with "Memories." in golden honey `#E5A83B`).
   - Subtitle: `Photography that tells your story, beautifully.`
   - Primary & Glassmorphism CTA buttons (`Explore Services` & `Book Now`).

3. **About Us Section**:
   - Overlapping tilted photo cards with custom drop shadow and border radius.
   - Heading: `Capturing Your Special Moments` featuring cursive romantic accent typography (*Great Vibes*).
   - Verbatim copy, key highlight points, and "Discover More →" action.

4. **Our Services Section (3x3 Grid)**:
   - 9 Photography service cards with custom scallop cutout dividers, circular maroon icons, titles, and subtitles:
     1. **Wedding Photography** (*Your special day, our focus*)
     2. **Pre-Wedding Photography** (*Love in Every Frame*)
     3. **Engagement & Roka Ceremony** (*A New Beginning*)
     4. **Haldi Ceremony** (*Tradition in Every Splash*)
     5. **Mehendi Ceremony** (*Art on Your Hands*)
     6. **Sangeet & Reception** (*Dance, Celebrate, Repeat*)
     7. **Portrait Photography** (*Timeless Expressions*)
     8. **Fashion & Model Photography** (*Style in Every Shot*)
     9. **Cocktail & Pool Party Photography** (*Vibes, Shots & Cheers*)
   - Interactive modal popup with complete service details and direct booking action.

5. **Our Gallery Section**:
   - Asymmetric 4-column masonry grid layout.
   - Interactive full-screen Lightbox image viewer with captions.

6. **Why Choose Us Section**:
   - 5 feature cards with blush circular badges, titles, and copy:
     - *Professional Experience*
     - *Creative Photography*
     - *On-Time Delivery*
     - *Friendly Support*
     - *Memories That Last*

7. **Testimonials Section**:
   - Client reviews (*Priya Sharma*, *Arun Kumar*, *Sneha Ramesh*) with 5-star ratings.
   - Carousel navigation controls (previous/next and active indicator dots).

8. **Book Your Photography Session (Inquiry Form & Contact)**:
   - Romantic floral bokeh backdrop.
   - Direct contact channels (Call, Email, and Location pills).
   - Complete interactive inquiry form with validation (Name, Email, Phone, WhatsApp, Event Date, Event Type dropdown, Location, Message).
   - Instant confirmation success view.

9. **Footer Section**:
   - 4-column brand layout with quick links, contact info, and social icons (Facebook, Instagram, YouTube).
   - Bottom copyright bar.

## 🚀 How to Run Locally

### 1. Development Mode
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
npm run preview
```
